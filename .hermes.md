# Project Agent Rules

Hermes: load this file as the compact entry point for agent work in this repo.

## Start Here
- Read `docs/PROJECT_STRUCTURE.md` for architecture before feature work.
- Read `.hermes/plans/` for the current implementation plan.
- Preserve unrelated local changes; stage only files in scope.

## Workflow
- Use a scoped branch per change.
- TDD for core logic (`src/core/*`): write/update tests before/with implementation.
- Run `npm test` before claiming success.
- No MCP server yet — core/CLI first (see `cli-core-before-mcp` skill).
- Update docs when behavior, setup, architecture, or roadmap changes.

## Safety
- Do not commit secrets, tokens, local `.env`, or API keys.
- `LlmClient` is always an injected interface — never hardcode a provider call
  inside `core/`.
